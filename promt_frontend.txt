================================================================================
PROMPT FRONTEND: Halaman Program Kerja + Sie
================================================================================
Proyek ini menggunakan Docker (service: proker_frontend)
Frontend: React + Vite + Tailwind CSS v4
Lokasi project: frontend_manajemen_proker/

--------------------------------------------------------------------------------
KONTEKS PROYEK
--------------------------------------------------------------------------------
- Styling     : Tailwind CSS (sudah terinstall, IKUTI style yang ada)
- API calls   : src/services/ApiService.jsx → fetchApi.getApi(), postApi(), putApi(), deleteApi()
- Toast       : src/components/ui/Toast.jsx (success/error/confirm)
- Sidebar     : src/components/layout/Sidebar.jsx (tree menu dari localStorage "permission")
- Routes      : src/Routes.jsx (pakai createBrowserRouter, Layout sebagai wrapper)
- Utils       : src/services/Utils.jsx → getStorage(), setStorage(), hasAccess()

Contoh halaman : src/page/Dashboard.jsx (untuk style & layout reference)
Contoh CRUD    : src/page/MenuPage.jsx (untuk pattern CRUD lengkap)

IKUTI PATTERN DAN STYLE YANG SUDAH ADA. Jangan ubah style global.

--------------------------------------------------------------------------------
BACKEND API YANG TERSEDIA
--------------------------------------------------------------------------------
Semua API butuh auth:sanctum (header Authorization: Bearer <token>).
fetchApi sudah handle token secara otomatis.

1. Program Kerja:
   GET    /api/program-kerja           → daftar (paginated)
   POST   /api/program-kerja           → buat baru { name, description, start_date, end_date, id_auth_user_leader }
   GET    /api/program-kerja/{id}      → detail
   PUT    /api/program-kerja/{id}      → update
   DELETE /api/program-kerja/{id}      → hapus

2. Program Sie:
   GET    /api/program-sie             → daftar (paginated)
   POST   /api/program-sie             → buat baru { id_program, sie_name, description }
   GET    /api/program-sie/{id}        → detail
   PUT    /api/program-sie/{id}        → update
   DELETE /api/program-sie/{id}        → hapus

3. Program Sie Member:
   GET    /api/program-sie-member           → daftar (paginated)
   POST   /api/program-sie-member           → buat baru { id_sie, id_auth_user, role }
   GET    /api/program-sie-member/{id}      → detail
   PUT    /api/program-sie-member/{id}      → update
   DELETE /api/program-sie-member/{id}      → hapus

BAGIAN 1: SIDEBAR - SUB-ITEM DINAMIS PROGRAM KERJA
================================================================================

Menu "Program Kerja" SUDAH ADA di database sys_menu (id_menu_parent = 2, url = /program-kerja).
Sidebar sudah otomatis menampilkan menu ini dari localStorage "permission" via API tree.

YANG PERLU DILAKUKAN: Modifikasi Sidebar.jsx supaya menu "Program Kerja" punya
sub-item dinamis yang menampilkan DAFTAR NAMA program kerja dari API.

Cara kerja:
1. Saat user klik menu "Program Kerja" di sidebar (expand), fetch data dari:
   GET /api/program-kerja (pakai fetchApi.getApi("/program-kerja"))
2. Tampilkan hasilnya sebagai sub-item di bawah "Program Kerja"
   - Setiap sub-item menampilkan NAMA program kerja (field: name)
   - Klik sub-item → navigasi ke /program-kerja/{id_program}
3. Sub-item ini berbeda dari children biasa (yang dari permission tree).
   Ini adalah children DINAMIS yang di-fetch dari API saat menu di-expand.

Implementasi di Sidebar.jsx:
- Di komponen MenuItem, deteksi jika menu.url === "/program-kerja"
- Jika ya, saat tombol expand diklik:
  - Fetch daftar program kerja dari API
  - Simpan di local state
  - Render sebagai sub-item NavLink biasa (ikuti style yang sudah ada)
  - Setiap item link ke /program-kerja/{id_program}
  - Icon sub-item: fas fa-folder-open atau fas fa-file-alt
- Loading state: tampilkan spinner kecil atau teks "Memuat..." saat fetch
- Jika API error atau data kosong, tampilkan "Belum ada program kerja"

PENTING:
- Jangan hapus logic children yang sudah ada (untuk menu permission biasa)
- Sub-item dinamis ini HANYA untuk menu dengan url === "/program-kerja"
- Ikuti style sub-item yang sudah ada (ml-8, border-l-2, text-sm, dll)
- Saat sidebar dalam mode minimize (collapsed), sub-item muncul sebagai popup
  (ikuti behavior popup yang sudah ada untuk parent menu)

BAGIAN 2: HALAMAN LIST PROGRAM KERJA
================================================================================

Buat file: src/page/ProgramKerjaPage.jsx

Halaman ini menampilkan daftar semua program kerja dalam bentuk card atau tabel.
IKUTI style Dashboard.jsx (bg-gray-50, card putih, border-gray-200, rounded-lg, shadow-sm).

Fitur:
- Header: judul "Program Kerja" + tombol "Tambah Program Kerja"
- List/Card setiap program kerja:
  - Nama program (bold)
  - Deskripsi (text-gray-500, truncate jika panjang)
  - Status (badge warna: aktif=hijau, selesai=biru, dll)
  - Tanggal mulai - selesai
  - Tombol: Edit, Hapus
- Klik pada card/row → navigasi ke detail /program-kerja/{id}
- Modal/Form tambah & edit program kerja:
  - Input: name (required), description, start_date, end_date
  - Gunakan komponen InputText yang ada di src/components/ui/InputText.jsx
  - Submit pakai fetchApi.postApi() / putApi()
- Hapus: tampilkan Toast confirm, lalu fetchApi.deleteApi()
- Setelah create/update/delete, tampilkan Toast success/error
