

**Prompt Tambahan: Migrasi ke Tree Menu API**

**Objective:** Perbarui logika pengambilan (fetching) Menu di Frontend untuk menggunakan endpoint API Tree-Structured yang baru.

**Konteks:**
Backend telah diperbarui untuk menyediakan endpoint khusus menu dalam format hirarkis (tree). Sebelumnya, frontend mungkin mengambil list flat dari `/api/sys-menus` dan membangun tree secara manual, atau hanya menampilkan list flat. Kita perlu migrasi ke endpoint tree khusus ini untuk mendukung sub-menu bersarang dan manajemen izin yang dinamis.

**Kebutuhan Teknis:**

1. **Update API Endpoint:**
   - Ubah endpoint fetching menu dari `GET /api/sys-menus` menjadi:
     `GET /api/sys-menus/tree`
   - Pastikan request tetap menyertakan header `Authorization: Bearer <token>`.

2. **Menangani Struktur Data Rekursif:**
   - Format response baru mengembalikan array `children` untuk setiap item menu.
   - **Contoh Response:**
     ```json
     {
       "success": true,
       "data": [
         {
           "id_sys_menu": 1,
           "name": "Dashboard",
           "url": "/dashboard",
           "id_menu_parent": null,
           "children": []
         },
         {
           "id_sys_menu": 2,
           "name": "Management",
           "id_menu_parent": null,
           "children": [
             {
               "id_sys_menu": 3,
               "name": "User List",
               "url": "/users",
               "id_menu_parent": 2,
               "children": []
             }
           ]
         }
       ]
     }
     ```
   - Perbarui state management (misal: Redux, Vuex, atau React State) dan komponen UI (Sidebar, Navbar) untuk merender `children` ini secara rekursif.

3. **Integrasi dengan Custom Actions:**
   - Sesuai rencana *Custom Action API*, pastikan jika ada action baru yang ditambahkan via `/api/sys-group-permissions/add-action`, frontend dapat menemukan item menu yang tepat di dalam tree (berdasarkan `id_sys_menu`) dan memperbarui action-nya secara dinamis tanpa perlu reload seluruh tree menu.

4. **Pembersihan Logika Lama:**
   - Jika sebelumnya ada kode di sisi client yang mengubah list flat menjadi tree secara manual, kode tersebut harus dihapus dan diganti dengan penggunaan langsung struktur tree dari backend.

5. **Toast Notifications:**
   - Gunakan library [react-hot-toast](https://react-hot-toast.com/) untuk menampilkan notifikasi sukses atau error saat fetching data atau saat terjadi perubahan status (seperti update permission).

**Goal:** Pastikan sidebar/navigasi menu menampilkan item anak (child) yang bersarang di bawah induknya masing-masing sesuai data dari API.
